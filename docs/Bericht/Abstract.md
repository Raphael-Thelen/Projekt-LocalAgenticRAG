Lokale PDF-Wissensbestände enthalten häufig sensible oder lizenzrechtlich geschützte Inhalte und erfordern daher Retrieval- und Assistenzsysteme, die ohne Cloud-Übertragung auskommen. Vor diesem Hintergrund untersuchte diese Arbeit, ob ein lokal betriebenes Agentic-RAG-System auf Basis von Elasticsearch und dem Model Context Protocol (MCP) technisch praktikabel, reproduzierbar evaluierbar und für natürliche Nutzeranfragen hinreichend robust ist. Dafür wurde ein Forschungsprototyp entwickelt, der eine rekursive Multi-PDF-Ingestion mit Chunking und Metadatenanreicherung mit einer MCP-gestützten Tool-Schicht verbindet. Mit ElasticSearch implementiert und verglichen wurden die Retrieval-Strategien Exact, Phrase-Proximity, Fuzzy und KI-gestützt.

Die Evaluation erfolgte mit einer standardisierten 10-Fragen-Testbench in drei Modi (user, realistic_args, diagnostic_args), getrennten Retrieval-Metriken (Macro-Precision, Macro-Recall, Hit-Rate) und manueller Antwortbewertung (C/P/W, gewichteter Antwortscore). Über mehrere Iterationen stieg die Gesamt-Hit-Rate von 0.267 auf 0.433 (user), von 0.300 auf 0.500 (realistic_args) und von 0.567 auf 0.667 (diagnostic_args). Parallel verbesserten sich die gewichteten Antwortscores von 0.333 auf 0.550, von 0.400 auf 0.600 und von 0.467 auf 0.650. Methodisch zeigte sich, dass serverseitiges Query-Rewrite den stärksten Hebel für Exact-Retrieval darstellt, während Fuzzy über alle Modi hinweg die stabilste Leistung erreichte. In einem zusätzlichen User-Benchmark lagen Fuzzy und Smart bei gleicher Hit-Rate (0.800), wobei Fuzzy beim gewichteten Antwortscore leicht vorn lag (0.950 gegenüber 0.900).

Insgesamt zeigt die Arbeit, dass ein lokaler Agentic-RAG-Ansatz mit Elasticsearch und MCP eine tragfähige Architektur für datenschutzsensible Wissensarbeit darstellt, jedoch besteht weiterer Optimierungsbedarf, insbesondere bei Proximity-basiertem Retrieval.
